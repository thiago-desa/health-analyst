# Examples

All files in this folder are **clearly fictional** documentation samples.

- `fictional-health-review.md` - a made-up checkup plus a limited consumer genetics summary, with citations treated as example fetches, no diagnosis, and a see-a-clinician close.

Do not copy real reviews, lab PDFs, imaging, genome files, or any person's health data into this folder. Do not present a fictional review as a real clinical report.
